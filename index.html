Featured · End-to-End DevOps Lab
Production-Grade Flask App on AWS EKS
A full DevOps platform built from scratch — local Docker Compose stack through to a live, auto-scaling Kubernetes deployment on AWS with automated CI/CD. A Python Flask API serves health, metrics, and readiness endpoints. The monitoring stack (Prometheus, Grafana, Alertmanager, cAdvisor, Node Exporter) runs alongside the app. Infrastructure is provisioned via modular Terraform across four modules: vpc, eks, ecr, and cloudflare. Kubernetes manifests handle deployments, ingress, HPA, and cert-manager SSL. Every push to main triggers a 3-stage GitHub Actions pipeline: test → build & push to ECR → deploy to EKS. OIDC authentication throughout — no long-lived AWS credentials stored anywhere.

Modular ALB + Private EC2 Infrastructure
Production-style AWS infrastructure built with Terraform. An ALB routes traffic to private EC2 instances inside a custom VPC — no direct internet exposure. Refactored from a flat layout into a three-module architecture (vpc, alb, compute) using moved.tf blocks to eliminate state destruction. Reduced a 19-destroy plan to zero.
